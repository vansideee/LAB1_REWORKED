# Операционные системы: Лабораторная работа №1

**Тема:** Создание процессов, передача параметров через командную строку и синхронизация (Windows API).

## 📝 Условие задачи

Разработать решение, состоящее из трех отдельных программ (процессов):
1.  **Creator** — утилита для создания бинарного файла данных.
2.  **Reporter** — утилита для формирования текстового отчета на основе бинарного файла.
3.  **Main** — управляющая программа, которая координирует работу утилит.

---

## ⚙️ Логика работы компонентов

### 1. Утилита Creator
Консольное приложение, которое принимает параметры через командную строку.
*   **Аргументы запуска:** `имя_бинарного_файла` `количество_записей`.
*   **Функции:**
    1.  Запрашивает с консоли данные сотрудников (ID, имя, отработанные часы).
    2.  Записывает введенные данные в указанный бинарный файл.
    3.  Использует структуру:
        ```cpp
        struct employee {
            int num;        // ID сотрудника
            char name[10];  // Имя
            double hours;   // Часы работы
        };
        ```

### 2. Утилита Reporter
Консольное приложение для генерации отчетов.
*   **Аргументы запуска:** `имя_бинарного_файла` `имя_файла_отчета` `почасовая_оплата`.
*   **Функции:**
    1.  Считывает данные из бинарного файла, созданного *Creator*.
    2.  Вычисляет зарплату для каждого сотрудника (`зарплата = часы * тариф`).
    3.  Формирует текстовый отчет со списком сотрудников и начисленной зарплатой.

### 3. Программа Main (Основная)
Координирует выполнение.
*   **Функции:**
    1.  Запрашивает у пользователя имена файлов и количество записей.
    2.  Запускает процесс **Creator** (`CreateProcess`), передавая параметры через командную строку.
    3.  Ожидает завершения процесса **Creator** (`WaitForSingleObject`).
    4.  Выводит содержимое созданного бинарного файла на экран.
    5.  Запрашивает имя файла отчета и ставку оплаты.
    6.  Запускает процесс **Reporter** (`CreateProcess`).
    7.  Ожидает завершения процесса **Reporter** (`WaitForSingleObject`).
    8.  Выводит готовый текстовый отчет на экран.

## 🛠 Технический стек

*   **Язык:** C++
*   **Платформа:** Windows (Windows API)
*   **Среда разработки:** Visual Studio
*   **Ключевые технологии:**
    *   `CreateProcess` — запуск дочерних утилит.
    *   `WaitForSingleObject` — синхронизация (ожидание завершения).
    *   Работа с файлами (`fstream`, `ios::binary`).

## 📂 Структура проекта

Решение Visual Studio состоит из 3 проектов:

```text
Solution/
├── Creator/        # Утилита записи в бинарный файл
├── Reporter/       # Утилита создания отчета
├── Main/           # Точка входа, управление процессами
└── employee.h      # Общий заголовочный файл (структура данных)
```
